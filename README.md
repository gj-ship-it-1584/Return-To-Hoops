# Return to Hoops

Personal training log PWA for getting back to dunking: 12-week cycles, swap catalog, exercise diagrams, body/labs log and trends. Offline-first (IndexedDB), optional Firebase sync, hosted on GitHub Pages.

See [SETUP.md](SETUP.md) to install and deploy.

```
npm install
npm run dev     # local
npm test        # schedule, progression and content tests
npm run build   # production build in dist/
```
